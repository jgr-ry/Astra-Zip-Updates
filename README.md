# Astra Zip

**Astra Zip**, de JoseGR: comprime y extrae ZIP, 7Z, RAR, TAR y más usando todos los núcleos, con una interfaz al estilo de Apple. Para Windows 10 y 11.

## Descargar

**[Descargar Astra Zip 0.3.0 para Windows](https://raw.githubusercontent.com/jgr-ry/Astra-Zip-Updates/main/releases/0.3.0/Astra%20Zip_0.3.0_x64-setup.exe)** · [novedades](releases/0.3.0/NOTES.md)

1. Abre el instalador. Como aún no está firmado con certificado, Windows puede decir "Windows protegió tu PC": pulsa *Más información* → *Ejecutar de todas formas*.
2. Elige idioma, acepta la licencia y pulsa *Instalar* (no pide administrador). Si a tu PC le falta WebView2, el instalador lo pone primero.
3. La primera vez, Astra Zip te ayuda a configurarlo: idioma, aspecto, menú del Explorador y formatos.

Astra Zip se actualiza solo desde aquí (Ajustes › Actualizaciones): cada versión va firmada por JoseGR y no instala nada que no lleve su firma.
